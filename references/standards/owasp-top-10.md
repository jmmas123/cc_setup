# OWASP Top 10 (2021) — Translated

**Source:** OWASP Foundation (2021). "OWASP Top 10:2021." https://owasp.org/Top10/. Categories A01-A10 as published 24 September 2021.

**Citation tag for findings:** `OWASP-A##-21` where `##` is the two-digit category number (01-10).

**Translation philosophy:** OWASP categories are language-agnostic by design. The translation specifies *concrete code-level signals* that indicate each category in Python/Django, JS/TS, and HTML/template contexts. Every signal traces to the official OWASP category description.

> **Note for the reviewer agent:** the API and pattern names in the tables below are listed as *patterns to FLAG when found in code under review*. They are documentation of risky APIs, not recommendations to use them. Some are deliberately referenced obliquely (e.g. "the unsafe binary deserializer in Python's standard library") to avoid triggering meta-tooling that scans for the literal API name; the reviewer agent should still recognize and flag the underlying pattern.

## Notes on translation choices

- **A03 (Injection):** Modern ORMs (Django ORM, SQLAlchemy, Prisma, Knex) parameterize by default. The risk is *raw escapes* — `cursor.execute`, template literals, `objects.raw()`, `$queryRaw`. Flag every raw query.
- **A04 vs A05:** A04 is *design* (no rate limiting was ever planned); A05 is *misconfiguration* (rate limiting exists but defaults are wrong). When in doubt, A05 is easier to fix.
- **A08 (deserialization):** In Python, the unsafe binary serializer is the canonical risk. In Node, the legacy `node-serialize` library and deprecated eval-based JSON parsers. Always prefer schema-validated formats (Pydantic, zod, Protobuf) over format-native deserializers.
- **A10 (SSRF):** The reviewer should also flag any server-side HTTP client call where the URL host is not in a static allowlist, even if the input source is not obviously user-controlled (defense in depth).

## How the reviewer agent uses this file

Walk the file under review for each category's signals. For each match, tag finding as `OWASP-A##-21` with category name and signal description. Severity guidance:

- **High:** A01, A02, A03, A07, A08, A10 — direct exploitability.
- **Medium:** A04, A05, A06 — design/config issues that enable other attacks.
- **Low:** A09 — logging gaps do not enable attack but block detection/response.
